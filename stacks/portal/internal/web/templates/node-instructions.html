2 · Pilih cara koneksi

Pakai kapan: mesin sudah ada Docker — VPS, Raspberry Pi OS, mini PC, home server. Container auto-restart dan upgrade tinggal ganti image. Cocok untuk mayoritas node rumahan.

docker run
{{.DockerCmd}}

Token bersifat rahasia — jangan tempel di chat publik. Jaringan container: pastikan mesin node bisa menjangkau origin yang dipilih (mis. {{.Origin}}).

Pakai kapan: mesin tanpa Docker, server produksi yang butuh systemd, atau OS non-Linux. Binary ringan, jalankan sebagai service supaya hidup lagi setelah reboot. Cocok untuk VPS kecil dan mesin yang dikelola penuh.

install binary + service
{{.BinaryCmd}}

Ganti linux-amd64 dengan linux-arm64 bila mesinnya ARM (Raspberry Pi 4/5 64-bit).

3 · Setelah tersambung

  • Node muncul di daftar node dengan status TERHUBUNG.
  • Di form hostname, node ini bisa dipilih pada kolom Connector / node — origin otomatis ikut terisi.
  • Koneksi putus? Portal menandai OFFLINE; bila cloudflared restart dengan client_id baru, tombol Ikat ke … muncul untuk rebind.
