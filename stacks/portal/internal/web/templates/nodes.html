Ground rules

  • Traffic on one tunnel is shared evenly across all connected connectors. The origin must be reachable from every node in that tunnel.
  • Want per-machine (separate, deterministic origins)? Use one tunnel per node — you can create one right from this page.
  • Portal default origin: {{.Origin}}. Override it per node when adding a connector.
